💡 Aplicativo de Frases Inspiradoras

Aplicativo mobile desenvolvido com React Native, Expo e TypeScript, que apresenta frases motivacionais de forma aleatória por meio de um botão interativo.

O projeto tem como objetivo proporcionar uma experiência simples e intuitiva, oferecendo mensagens de inspiração e incentivo para o dia a dia.

🚀 Tecnologias utilizadas

React Native
Expo & Expo Go
TypeScript (TSX)
StyleSheet

⚙️ Funcionalidades

Exibição de frases inspiradoras.
Geração aleatória de novas frases.
Botão interativo para atualizar as mensagens.
Interface intuitiva e responsiva.
